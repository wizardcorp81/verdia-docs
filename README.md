## Publicação com GitHub Pages

1. Usar um repositório dedicado à documentação. No GitHub Free, usar um repositório público.
2. Enviar estes arquivos à raiz da branch `main`.
3. Em Settings → Pages, selecionar “Deploy from a branch”, branch `main`, pasta `/ (root)` e salvar.
4. Aguardar o deploy. Usar o endereço exibido em Pages e verificar a página inicial e o link do SDD.

O endereço padrão terá o formato `https://USUARIO.github.io/REPOSITORIO/`. Esse exemplo não é confirmação de publicação.

## Conteúdo público

Somente documentação e estudos de marca. Não colocar código do aplicativo, credenciais, dados de pacientes, backups, arquivos de ambiente ou anexos privados neste repositório. Publicar o documento não implementa nem hospeda o CRM.
